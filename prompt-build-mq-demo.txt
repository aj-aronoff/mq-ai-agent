   So the enhancement is simply to put that instruction on the ticket. Take a

       Diagnose ACME.COMMERCE.QUEUE on QMS1

   The enhancer should read the ticket JSON, add the instruction in its own
   field, and write the ticket back out. Keep the wording exactly in that
   form, since that is what the agent parses. Don't add MQSC commands or a
   remediation write-up at this stage; the agent produces those itself once it
   has the instruction. This is the first version of the enhancement step and
   I expect to add more to it later, so keep it a separate script from the
