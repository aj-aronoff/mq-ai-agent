An automated MQ monitoring pipeline that detects problematic queues, generates structured tickets, and enriches them with precise diagnostic instructions for the IBM MQ AI Agent. When a queue has messages but no consumer, the system creates a ticket, enriches it, and passes it to the live MQ AI Agent for diagnosis. The agent returns actionable recommendations — including MQSC remediation commands — while keeping humans in control of every change. Built entirely with IBM Bob on Windows 11 + WSL.
